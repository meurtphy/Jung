# Thought Forge — UI de démonstration

Cette version inclut une interface front-end fonctionnelle (HTML/CSS/JS) avec:

- interactions JavaScript actives (boutons qui répondent)
- style modernisé (cartes, thème sombre/clair)
- animations légères et fluides
- historique local des prompts

## Lancer rapidement

Ouvrir simplement le fichier `public/index.html` dans le navigateur, ou servir le dossier `public/`.

Exemple avec Node:

```bash
npx serve public
```

Puis ouvrir l’URL affichée.
